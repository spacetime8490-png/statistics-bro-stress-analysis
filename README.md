# STATISTICS PRO - Academic Stress & Wellbeing Intelligence Suite

A professional web application for academic stress analysis, mental health diagnostics, and statistical intelligence built on empirical student survey cohorts.

## 🚀 Live Demo on GitHub Pages
This repository is configured for immediate deployment via **GitHub Pages**.

### How to Enable GitHub Pages:
1. Go to your repository **Settings** on GitHub.
2. In the left navigation, click **Pages** (under 'Code and automation').
3. Under **Branch**, select main (or master) and folder / (root).
4. Click **Save**.
5. Within 1-2 minutes, your website will be live at:
   https://<your-username>.github.io/<repository-name>/

## 🌟 Key Features
- **Executive Dashboard:** Real-time KPI summary (Sample size, Stress rate, Sleep deficit, Critical burnout index) with Chart.js visualization.
- **72+ Statistics Pro Suite:** Over 72 parametric, non-parametric, regression, multivariate, and hypothesis tests with LaTeX formula breakdowns and step-by-step guides.
- **Live Data Management:** Complete 72-student survey response registry with real-time filtering, branch categorization, and student diagnostics.
- **20x20 Correlation Heatmap:** Color-coded academic correlation matrix across all 20 survey dimensions.
- **Early-Warning Scorecard:** High-risk student identification with priority counseling alerts.
- **Personalized Prescription Engine:** 11 clinical/academic prescription archetypes (ARCH-01 to ARCH-11) dynamically tailored to each student's specific multi-dimensional survey profile.
- **Interactive Stress & Wellbeing Calculator:** Real-time multi-variable stress assessment with instant actionable recovery prescriptions.
- **Zero Faculty Postponement Rule:** All advice is strictly student-centered (4-Day reverse planning, 25/5 Pomodoro, circadian anchor, 15-minute office hour sprints).
